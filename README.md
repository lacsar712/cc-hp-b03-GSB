# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。放行记录须经两名不同质检员会签后才对外生效：炮制员写入后进入「待会签」，未满两人时总表对外视图标记待会签（详情仍可见原文），满两人后标记「会签完成」。

## 端口

|------|------|

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| processor | herb123456 | 炮制员，可写入记录，不能会签 |
| checker | check123456 | 质检员，可会签 |
| checker2 | check2_123456 | 质检员，可会签（第二名会签人） |

## 启动

```bash
cd projects/14-herb-process-record
docker compose up --build
```

## 验收

1. processor 登录后，甘草为放行，黄芩为未放行（温度过低）。
2. 再写一条温度 200 的清炒，结论仍是未放行。
3. checker 看不到写入按钮，processor 点会签返回 403。
4. processor 写一笔甘草放行，记录进入待会签，总表对外视图为待会签。
5. checker 在会签台详情点会签并填意见，只签一人时仍待会签；同一质检员不能重复会签。
6. checker2 另开会话登录并会签，满两人后标记会签完成、对外生效，服务端留下两名质检员的会签履历。
