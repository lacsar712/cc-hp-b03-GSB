# 饮片炮制记录台

一条记录是一整包炮制文书，里面是工序数组，不是拆成多列指标的普通表单。清炒温度和时长不在范围内就不能放行。

放行记录须两名不同质检员在会签台会签并填写意见，满两人后才对外生效（会签完成）。炮制员写入放行记录后进入待会签；未满两人时总表对外视图标记待会签，详情仍可见放行原文。炮制员不能会签。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3193 |
| 接口 | http://localhost:8193 |
| PostgreSQL | localhost:54393 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| processor | herb123456 | 炮制员，可写入记录，不能会签 |
| checker | check123456 | 质检员，可会签 |
| checker2 | check123456 | 质检员，可会签 |

## 启动

```bash
cd projects/14-herb-process-record
docker compose up --build
```

## 验收

1. processor 登录后写入一条甘草清炒（温度 120、时长 12），结论为放行；总表对外视图标记待会签，详情可见放行原文。
2. checker 登录后从顶栏进入会签台，在待会签列表选中该甘草，填意见提交会签；只签一人时仍标记待会签（1/2）。
3. checker2 登录后对同一记录再次会签；满两人后该记录标记会签完成，进入已完成列表，会签履历记录两条意见。
4. processor 看不到会签按钮，直接调用会签接口返回 403。
5. 黄芩（温度 40）以及温度 200 的清炒记录仍为未放行，不进入会签流程。
